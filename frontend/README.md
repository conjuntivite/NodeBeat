# NodeBeat — frontend

Painel web em Flutter, com o design system Trade UI (cópia em `design-system/`).

- Testes: `flutter test`
- Análise: `flutter analyze`
- Regenerar tokens (após mudar `design-system/tokens.json`): `dart run tool/gen_tokens.dart`
- Build: `flutter build web` (saída em `build/web`, servida na mesma origem da API `/api`)

Fontes em `assets/fonts` sob licença OFL (textos em `OFL-*.txt`).
